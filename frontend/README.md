## How to install 💻

```bash
#First clone this project on your preference path

$ git clone https://github.com/Luan4560/SOAP-health.git

# Install the dependecies

$ yarn or npm install

# Go to server (API) install dependecies 

$ yarn or npm install

# Run the server 

$ yarn dev or npm run dev 

# The server should run on port 3333

# After that, just initilialize the frontend with:

$ yarn dev
```
